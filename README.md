# Stealth AI

> A sleek, always-on-top AI assistant for Windows — with a secure Auth Manager module.  
> Download the latest installers from **Releases** below.

## 🧩 What’s inside

- **Stealth AI (Assistant)** – the main app
- **Stealth AI — Auth Manager** – handles secure Google sign-in, subscriptions, keys

Both apps share a single session, so you sign in once.

## ⬇️ Downloads

Grab the latest installers and portable executables from:  
**👉 [Releases](../../releases/latest)**

You’ll find:
- `StealthSuite-Setup-<version>.exe` – One installer that updates/installs **both** apps
- `Stealth AI-<version>-x64.exe` (main app installer)
- `Stealth AI-Portable-<version>-x64.exe`
- `Stealth AI-Auth Manager-<version>-x64.exe` (auth installer)
- `Stealth AI-Auth Manager-Portable-<version>-x64.exe`

> Tip: If you’re not sure, use the **Suite Installer** — it installs/updates both apps at once.

## 🔄 Auto-Updates

When a new version is available, Stealth AI prompts you to update on launch.  
You can defer up to **5 days**. On day 5, the update is required to continue.

## 🛡️ Security & Privacy

- Google Sign-In (Supabase)  
- Device binding  
- Local data is stored under `%APPDATA%\Stealth AI`  
- No telemetry by default

## 🧰 Requirements

- Windows 10/11 (x64)
